# Daksh Jain Accessible Portfolio — Advanced CSS3 Edition

## Included
- Semantic HTML5 structure
- CSS Grid for two-dimensional layouts
- Flexbox for navigation and component alignment
- Mobile-first responsive breakpoints
- CSS custom properties for theme tokens
- Light/dark mode persisted with localStorage
- Accessible skip link, labels, focus-friendly controls
- SVG-ready icon/decorative architecture
- Responsive mobile navigation
- Reveal-on-scroll animations with reduced-motion support
- Back-to-top control
- Responsive project/skill cards

## Run
Open `index.html` in a browser, or use VS Code Live Server.

No build tools or npm packages are required.
