# Daksh Jain - Accessible HTML5 Portfolio

A multi-page semantic HTML5 portfolio focused on accessibility, keyboard navigation and SEO.

## Pages
- index.html
- about.html
- projects.html
- contact.html

## Customize
1. Replace `Daksh Jain` with your name.
2. Update the About, Education and Skills sections.
3. Replace project names/descriptions and project links.
4. Update meta descriptions and page titles.
5. Add your own profile image if desired.
6. Open `index.html` in a browser.

## Lighthouse
Run Lighthouse in Chrome after customizing and deploying. The project includes semantic HTML, labels, keyboard focus, skip navigation, descriptive metadata and accessible form structure. A perfect score cannot be guaranteed because Lighthouse also evaluates the final content, links, performance, hosting and other runtime factors.
